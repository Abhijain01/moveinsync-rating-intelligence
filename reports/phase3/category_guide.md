# Category guide

Write the ids in the `labels` column, separated by `|`, or `NONE`.

| id | meaning |
|---|---|
| LOGIN_SESSION | Forced logout / repeated re-login / SSO re-authentication |
| ACCESS_OTP | Cannot sign in / register (OTP not received or delayed) |
| INSTALL_ERROR | 'Not installed from Play Store' error / needs uninstall-reinstall |
| CRASH_LOAD_PERF | Crashes, blank screen, not opening, slow or endless loading |
| DEVICE_COMPAT | Device / OS specific failures |
| TRACKING_LOCATION | Live tracking / GPS / map location wrong, stale or stuck |
| ETA_PICKUP_TIME | ETA / pickup time inaccurate, changing, missing or unreasonably early |
| NOTIFICATIONS | Notifications / pop-ups: too many, wrong, delayed or missing |
| BOOKING_FAILURE | Cannot book/schedule; bookings or schedules missing, wrong or not visible |
| BOOKING_RULES | Booking window, cut-off, waitlist and transport-policy rules |
| CANCEL_EDIT | Cannot cancel/edit; cancellation not honoured |
| ADDRESS_LOCATION_MGMT | Pickup/drop address or nodal point cannot be changed or is wrong |
| NO_SHOW | No-show marking / consequences disputed |
| BOARDING_QR_OTP | Boarding: QR scan, driver PIN/OTP, check-in |
| ROUTING_ALLOCATION | Routing, clubbing, sequence and cab allocation |
| VEHICLE_DRIVER_OPS | Cab late/not provided, driver conduct, vendor / transport-team failures |
| SUPPORT_HELPDESK | Helpdesk / customer support unreachable, unhelpful or silent |
| FORCED_RATING | Forced / repeated rating or feedback prompt, cannot skip |
| FEEDBACK_FLOW_BROKEN | Trip rating/feedback cannot be given or edited; no reply to feedback |
| UI_UX | Interface not user-friendly, confusing or worse after redesign |
| FEATURE_REQUEST | Missing feature requested (dark mode, driver chat/call, co-passenger view, etc.) |
| DRIVER_CONTACT | Cannot call/chat with driver; call audio problems |
| PERMISSIONS_CONSENT | Permission / consent prompts, privacy, battery |
| SAFETY | Safety / security concern mentioned (women's safety, SOS, speeding, late night) |
| UPDATE_REGRESSION | Problem attributed to an app update / redesign |
| WORKPLACE_FEATURE | Desk / seat / meeting-room (non-commute) feature |

A review can have several categories. Label what the reviewer complains about, not how angry they are.
Generic complaints such as 'worst app' with no specific problem are NONE.
