# Short note for submission form field 7

I confirmed the employee app (com.moveinsync.ets), collected 24,314 reviews with English/India settings using google-play-scraper, and analyzed the latest 12 months: 2,856 reviews, including 846 rated 1-3 stars. A deterministic 26-category classifier gave precision 0.76, recall 0.65 and F1 0.70 on a frozen 100-review AI-labeled test. A 30-review human spot check is included; 13 category mappings used AI assistance, so it was not fully independent. Counts and root causes are therefore treated cautiously.

My recommendation is to investigate stability, instrument self-booking from day 1, improve authentication and feedback friction, and run a joint Product/Operations commute-reliability investigation with named owners and metrics. Credible safety failures receive same-day assessment. I translated review evidence into competing root-cause hypotheses, prioritized work using a transparent model and sensitivity analysis, and wrote implementation tickets with acceptance criteria and guardrails. No rating lift is promised: Google weights recent ratings and public reviews cannot prove causal impact.

Tools: Python, pandas, google-play-scraper, pytest and regex rules. Claude assisted the original research, coding, tests and labeling; ChatGPT/Codex helped review and correct the submission and reproduce its results. The corrected package includes the original review snapshot, manifest, generated report and an offline demo; all 85 tests pass with no skips. No paid model API is required. The reusable tool supports future collection, trend analysis and snapshot comparison.
